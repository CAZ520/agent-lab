# Python 基础补课计划（3 天）

> 目标：补齐 Python 基础，然后回到 `code/week01/wordcount.py` 继续做项目
> 每天约 1.5 小时：45 分钟看视频 + 45 分钟动手写

## ⚠️ 最重要的一条：不要从头看到尾

那套课程有上百小时，全看完要几个月。**只挑下面 9 个主题**，其他全部跳过。

| # | 主题 | 学到什么程度算够 |
|---|---|---|
| 1 | 变量与数据类型 | 会写 `a = 1` / `b = "abc"` / `c = 1.5`，知道 int / str / float / bool |
| 2 | 字符串与 f-string | 会拼接、切片 `s[0:3]`、`f"{a} 和 {b}"` |
| 3 | 列表 list | 增删改查、索引、切片、`len`、for 遍历 |
| 4 | 字典 dict | 取值、赋值、遍历 `items()`、`in` 判断 |
| 5 | if / elif / else | 会写多分支判断 |
| 6 | 循环 for / while | for 遍历、`range`、while、break |
| 7 | 函数 def | 参数、返回值、默认参数 |
| 8 | 文件读写 | `with open(...) as f`、`read()`、`readlines()` |
| 9 | 异常 try/except | 捕获 `FileNotFoundError` |

**跳过**：面向对象 class、装饰器、生成器、GUI、爬虫、数据库、多线程 —— 以后用到再学。

## 每天怎么学（1.5 小时）

1. **45 分钟看视频**：只看当天主题，看不懂就回退 15 秒重看
2. **45 分钟动手**：把视频里的例子**自己敲一遍**（不要复制粘贴），再自己改动两处

## 自测标准（比看视频更重要）

每学完一个主题，**关掉视频，默写一个 5–10 行的小程序**：

- 学过列表？→ 建一个列表、加两个元素、遍历打印、取最后一个
- 学过字典？→ 建一个字典、遍历打印键和值
- 学过循环？→ 打印 1 到 10 的平方
- 学过函数？→ 写 `is_even(n)` 判断是否偶数
- 学过文件？→ 读一个文件，把每行打印出来
- 学过异常？→ 文件不存在时打印中文提示，而不是抛一堆红字

**写不出来 = 没学会**，回去再看那一段。
