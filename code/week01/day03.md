## 常见坑

| 现象 | 原因 |
|---|---|
| `if x = 5:` 报 SyntaxError | 少写一个 `=`，判断要用 `==` |
| SyntaxError 指向 `if` 那行 | 忘了冒号 `:` |
| `range(1, 5)` 只到 4 | **含头不含尾**，要 1–5 得写 `range(1, 6)` |
| 程序卡住不动 | `while` 死循环，按 **`Ctrl + C`** 停 |
| 函数返回 `None` | 忘了写 `return` |
| IndentationError | `if` / `for` / `def` 下面的代码必须缩进 4 格 |
| 函数里改了变量外面没变 | 作用域问题。先记住一句：**函数内部定义的变量，外面看不见** |
